# Heyo

> Heyo is a social marketing platform for building and running online promotions — sweepstakes, contests, giveaways, quizzes and coupons. Businesses use Heyo's drag-and-drop campaign builder and landing pages to create interactive campaign apps that publish to the web, mobile and social networks. Heyo is operated as a Votigo company (per the platform.heyo.com footer) and is a portfolio company of 500 Global.

## Status for agents

Heyo publishes **no public API**. There is no OpenAPI, Swagger, GraphQL, AsyncAPI or MCP surface on any Heyo host, and no developer portal, API reference or API key signup. The phrase "Developer API" appears once on the heyo.com homepage as static marketing copy in a product-tier headline; it is not a link and resolves to no documentation. `/api`, `/developer`, `/developers`, `/docs` and `/api-docs` all return 404 on heyo.com, and `api.heyo.com`, `developer.heyo.com` and `docs.heyo.com` do not resolve in DNS. Every `/.well-known/` discovery path returns 404 on every Heyo host. An agent cannot integrate with Heyo programmatically; the product is used through its web UI at platform.heyo.com.

The enterprise Developer API marketed by Votigo (api.votigo.com) is a **Votigo** product, documented on votigo.com, which does not mention Heyo. It is deliberately not catalogued here — see the ownership note in apis.yml.
